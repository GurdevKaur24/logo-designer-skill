# Logo Designer (Claude Skill)

Logo Designer is a Claude skill that creates a small logo system for any business and delivers it as live, editable artboards on a Claude Design canvas.

Each request produces three artboards:

- a primary logo
- a reversed-color logo for dark or brand-colored backgrounds
- a standalone logo mark for favicons, app icons and avatars

**Triggers:** requests for a logo, wordmark, brand mark or reversed/white logo version, or a logo made in Claude Design.

**Not for:** editing an existing raster logo file, or creating full brand-guideline documents.

## Files

- `logo-designer.skill`: the skill package
- `Claude-skill.pdf`: documentation with a test prompt (KNOTRA clothing brand), comparing results with and without the skill
